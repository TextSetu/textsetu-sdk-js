# Contributing

**This repository is generated.** Its contents are mirrored from
`packages/sdk` in the TextSetu monorepo by an automated workflow, and any
commit made directly here is overwritten by the next release.

Everything under `src/generated/` is additionally generated from the
TextSetu OpenAPI specification, so it is not edited by hand in either
repository — a change there follows from a change to the API itself.

To propose a change, open an issue on this repository describing it.

API reference: <https://docs.textsetu.com/api>
